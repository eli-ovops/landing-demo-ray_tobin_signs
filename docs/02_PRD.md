# P2 PRD — L0 Concept Preview

## Objective

Demonstrate a clearer mobile-first presentation of publicly stated Ray Tobin Signs services and direct contact paths.

## Acceptance criteria

- One responsive static page works at desktop and 390px mobile width without horizontal overflow.
- One original hero image, with a clear concept/rights disclosure.
- Company facts are limited to publicly verified name, location, contact, establishment year, local manufacture, and service categories.
- No data collection, external writes, client media, third-party logo, review, testimonial, tracking, or backend capability.

## Non-scope

No deployment, customer-approved branding, production content, booking, payment, form endpoint, CMS, API, database, SEO release, or outreach.

## Risks / assumptions

This is an independent concept; it must never be presented as an approved customer site. All external release requires a fresh rights and fact review.
